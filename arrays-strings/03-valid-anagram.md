## Problem: Valid Anagram (Easy)

**Link:** https://leetcode.com/problems/valid-anagram/

### Approach

Use a frequency array to count the occurrences of each character in both strings. Compare the character frequencies of the two strings. If all frequencies are equal, the strings are anagrams.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The solution works efficiently by comparing character frequencies.
